# 実務向けデザイン更新（2026-08-22）

## 主な変更

- ダッシュボードで「今日の作業予定」を最優先表示
- 今日の日付・作業件数・管理作物数・次回収穫を実データから表示
- 全15画面へ共通の業務用デザインを適用
- 在庫管理、作業登録、売上編集、経費編集を全面改修
- AIアシスタントの画面・メニュー・関連コードを削除
- 作業カレンダーを横に広げて左右の余白を縮小し、トップページへ戻るボタンを調整
- ダッシュボード右側の不要な余白を解消
- ダッシュボード右上へ現在地の天気・気温・湿度・雨量・風速・3日予報を取得する機能を追加
- 左サイドバーとメニュー項目を拡大し、余白を減らして操作しやすく調整
- 全画面の「トップページへ戻る」ボタンを作業カレンダーの緑色デザインへ統一
- 圃場一覧・経営管理・在庫管理の戻るボタンをヘッダー右側の同一レイアウトへ統一
- 売上・経費・収支画面のナビゲーションと配色を統一
- スマートフォンでは在庫表をカード表示へ切り替え
- `null`の数値は`0`、空欄は「未設定」または「—」として表示
- CSS・JavaScriptへ更新番号を付与
- Service Workerを1つに統一し、HTMLはキャッシュしない方式へ変更

## Eclipseで開く方法

1. ZIPを任意の場所へ展開します。
2. Eclipseで「ファイル」→「インポート」を開きます。
3. 「Maven」→「既存Mavenプロジェクト」を選びます。
4. 展開した`demo`フォルダーを選択します。

## GitHubへ反映する前の確認

```bash
git status
git add src DESIGN-UPDATE.md
git commit -m "全画面を実務向けデザインに更新"
git push origin ver2
```

Renderで最新コミットのデプロイ完了後、Pixel 7aで古い表示が残る場合は、Chromeの対象サイトデータを一度削除してください。今回の更新後は、HTMLをService Workerへ保存しないため、次回以降の画面更新が反映されやすくなります。

天気を取得するときは、Chromeに表示される位置情報の確認で「許可」を選択してください。スマートフォンから利用する場合は、HTTPSで公開したURLを使用します。
