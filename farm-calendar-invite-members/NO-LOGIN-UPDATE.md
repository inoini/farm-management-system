## 導入
1. 現在のプロジェクトをバックアップします。
2. このZIPを展開し、中の「農業管理システム最新版/src」を現在の同名フォルダーに上書きします。mainだけでなくtestも必ず上書きしてください。
3. 現在のプロジェクトのコマンドプロンプトで以下を実行します。

```bat
set "PATH=%SystemRoot%\System32;%SystemRoot%\System32\WindowsPowerShell\v1.0;%PATH%"
mvnw.cmd clean package
```

4. BUILD SUCCESSを確認してから、起動・デプロイしてください。
