# 無料枠優先 AI農業管理システム 方針

## 基本方針
既存の農業管理システム・既存データ・既存機能は削除しない。
新機能は追加方式で実装する。
新たな月額課金を必要とするAPI・AI・外部サービスは導入しない。

## 無料で使う構成
- AI: Gemini 2.5 Flash の無料枠
- 天気: Open-Meteo
- DB: 現在の Neon PostgreSQL 無料枠を継続
- ソース管理: GitHub
- フロント: Thymeleaf / HTML / CSS / JavaScript
- バックエンド: Spring Boot / Java 21
- PWA: ブラウザ標準機能

## AI機能
- 作物・圃場・在庫・売上・経費を横断した相談
- 今週やるべき作業の優先順位
- 在庫不足警告
- 農薬の登録済み使用回数・収穫前日数の注意喚起
- 収穫準備
- 経営改善案
- 作物別の採算分析
- 天候を使った収穫目安

## 課金防止
- 有料AIモデルを必須にしない
- Google検索グラウンディング等の有料化し得る追加ツールは使用しない
- コンテキストキャッシュ等の有料機能は使用しない
- AI無料枠を超えた場合は自動的に有料課金へ切り替える仕組みを作らない
- 無料枠が利用できない場合はエラーメッセージを表示し、既存機能は通常利用できるようにする

## Renderについて
現在の farm-management-system の Render Web Service は既存の 0.5c-512mb プラン。
この既存契約は本改修では変更しない。
AI追加による別のRenderサービスや追加サーバーは作成しない。

## 安全な開発
- main ブランチは直接変更しない
- feat/ai-farm-copilot-v1 で開発
- Mavenビルド確認後に統合候補とする
- 本番反映は検証後に行う
